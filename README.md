# pAnno GUI

[pAnno](https://github.com/Wang-kaifei/pAnno) 的图形界面：填参数、点运行、看结果，不用敲命令行。

[![下载最新版](https://img.shields.io/github/v/release/pumpkin0312/pAnnoGUI?label=下载最新版)](../../releases/latest)

> **本程序不含 pAnno 本体**，只负责生成配置文件、启动 pAnno、展示结果。
> 你需要事先装好 pAnno（含 `pAnno.exe` 的 `pAnnobin` 文件夹）。

---

## 下载

到 [Releases](../../releases/latest) 下载 `pAnnoGUI-vX.X.X.zip`，解压后双击 `pAnnoGUI.exe`。

不需要安装 Python，不需要联网。目前只提供 Windows 版本。

首次运行时会让你指定 `pAnnobin` 文件夹的位置，选一次之后自动记住。

**Windows 提示"已保护你的电脑"**：点「更多信息」→「仍要运行」。没买代码签名证书的程序都会有这个提示。

详细使用说明见压缩包里的 `使用说明.md`。

---

## 能做什么

| 页签 | 内容 |
|---|---|
| **参数** | 表单填写 + 实时校验。文件不存在、格式不对、磁盘空间不够、基因组过大而并行参数偏高，填的时候就会提示，不用等跑崩了才发现 |
| **运行** | 阶段流水线进度、已运行时长、实时日志。点停止会连同 pAnno 启动的子进程一起结束 |
| **结果** | 结果文件按类别分组，可预览内容，附基本统计图表 |

---

## 参数怎么填

界面上带 ★ 的是必填项，其余都有合理默认值——**大多数情况下你只需要填必填项**。
鼠标悬停在参数名上会显示简要说明。

想了解每个参数的具体作用、以及内存不足、免疫肽组、低分辨数据等场景该怎么调，
见 **[参数说明.md](参数说明.md)**，里面逐个介绍了全部参数。

## 遇到问题

欢迎提 [issue](../../issues)，附上这三样能大幅提高解决速度：

1. **版本号** —— 标题栏或「关于」里能看到
2. **「运行」页的完整日志** —— 全选复制即可
3. **用的什么数据** —— 物种、基因组大小
