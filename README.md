# pAnno-desktop

[![下载最新版](https://img.shields.io/github/v/release/pumpkin0312/pAnno-desktop?label=下载最新版)](../../releases/latest)

**pAnno 的 Windows 完整发行版：图形界面 + pAnno 分析程序 + pFind 搜索引擎，下载即用。**

---

## pAnno 是什么

pAnno 是一个**蛋白质基因组学**（proteogenomics）分析流程，由中国科学院计算技术研究所 pFind 团队开发。它用质谱数据，找出参考蛋白库里**没有收录的新肽段**，再把它们定位回基因组，推断对应的编码区。可以用来发现未注释的基因、新的编码区和可变剪接。

```
① 建库      把基因组做六框翻译、转录组做三框翻译，去冗余，得到候选蛋白库
② 第一轮搜库  用 pFind 搜参考蛋白库，识别已知蛋白，学习样品中实际存在的修饰
③ 缩库 + 第二轮搜库  删掉已解释的谱图，按学到的修饰缩小候选库，再搜出新肽段
④ 回贴注释  把新肽段回贴到基因组和转录组，推断编码区，分组输出
```

## 这个发行版包含什么

| 组件 | 说明 |
|---|---|
| **图形界面** | 填参数、点运行、看结果，带输入检查、阶段进度、进程监视 |
| **pAnno** | 分析主程序，也可以单独在命令行使用 |
| **pFind** | 搜索引擎。基于 pFind 3.2.3 定制、专门用于 pAnno 的版本，只包含 pAnno 用到的部分 |
| **DBReducer** | 缩库程序 |

不需要另装 Python、pFind 或其他软件，也不需要联网。

## 下载与安装

到 [Releases](../../releases/latest) 下载，二选一：

- **`pAnno-desktop-v0.3.0-Setup.exe`**：安装包（推荐），默认装到 `C:\pAnno`
- **`pAnno-desktop-v0.3.0-portable.zip`**：免安装，解压即用

**系统要求**：
- 图形界面：64 位 Windows 10 / 11；命令行：64 位 Windows 即可（Windows 10 之前的系统未经测试）。
- 内存需求随基因组大小和参数设置增加，大基因组需要较大的内存。内存不够时的处理办法见《使用说明》第 7 节。

**安装路径和数据路径都不能包含空格。**

## 快速开始

**图形界面**：
1. 打开 pAnno-desktop，在「参数」页填好带 ★ 的必填项：基因组、参考蛋白库、GFF、MGF 文件夹、输出目录、中间库目录（存放翻译出的候选蛋白库，一般设为输出目录下的 `trans`）；有转录组的也填上（可以不填，只用基因组跑）。
2. 点「生成 pAnno.cfg」。
3. 在「运行」页点「▶ 运行」。
4. 跑完后自动跳到「结果」页。

**命令行**：

```bat
cd /d C:\pAnno\pAnnobin
pAnno.exe D:\work\pAnno.cfg 0
```

## 已知限制

- 质谱数据目前只支持 **pParse 导出的 MGF**，其他软件导出的格式计划在下一版支持。
- 路径不能包含空格。
- 只提供 Windows 版本。图形界面需要 Windows 10 / 11。
